# Kenのデンモク（REALITY歌配信向け）

ブラウザで歌唱待機・歌唱履歴・リクエストを管理するGitHub Pagesアプリです。

公開URL: https://y-tools.github.io/ken_ver1/

## リスナー画面

1. **歌唱中曲**とON AIR/OFF AIR表示
2. **01 楽曲検索**：曲名・アーティストをまとめて検索
3. **02 歌唱待機楽曲**：順番とリクエスト者を表示
4. **03 本日の歌唱履歴**：歌唱が完了した楽曲、終了時刻を日本時間で表示
5. **04 練習中楽曲**：練習曲を表示

「リクエストする」でフォームをポップアップ表示。配信開始中のみ送信可能。曲名・アーティスト・リクエスト者名を記録します。

## 管理画面

ページタイトルを約0.75秒長押し（PCではダブルクリックも可）すると管理画面への簡易入口が開きます。

PC画面は左から：リスナー画面プレビュー、歌唱待機曲（歌唱開始・完了・取り消し）、未分類リクエスト（歌唱待機・練習中・歌える曲への振り分け）、右端上下2分割の管理メモ・ChatGPT調査連携。

歌唱待機＋歌える曲の同時選択が可能です。配信開始・終了でON AIR表示とリクエスト受付を切り替えます。管理メモと曲ごとのメモ編集、配信レポートもあります。

**「さらに調べる」**は、曲名・アーティストについて楽曲情報、概要、公式歌詞掲載URLを調査するための**プロンプトを生成する機能**です。ChatGPTを新しいタブで開き、内容を貼り付けて利用します。ChatGPTへの自動送信・iframe埋め込み・API問い合わせは行いません。Google歌詞URL検索も別タブで開きます。

## 検索カタログ

| データ | 対象・形式 | 出典 |
|---|---|---|
| `catalog.json` | 世界の楽曲約58,800件、`[曲名,アーティスト,発売年]` | Wikidata（CC0） |
| `data/japanese_popular_10000.json` | 日本楽曲10,000件、1980–2026年（人気度の公式ランキングではない） | `data/songs_1980-2025.csv` / Wikidata（CC0） |
| `data/vocadb_100k/` | ボーカロイド・UTAU等の楽曲100,000件。20分割・検証用manifest付き | VocaDBの公開メタデータ（CC BY。出典表記を維持） |
| `data/extra_to_300k/` | 追加140,983曲。29分割・検証用manifest付き。重複除去後の検索対象をちょうど300,000曲に拡張 | VocaDBの公開メタデータ（CC BY。出典表記を維持） |
| `data/musicbrainz_700k/` | 追加700,000件。256個の2文字検索用バケットに分割し、必要なものだけ取得 | MusicBrainz Canonical Data（CC0） |

読み込み時に曲名＋アーティストを正規化して重複表示を抑えます。現在の検証済みユニーク楽曲数は **1,000,000曲**（以前の300,000曲＋MusicBrainz由来の追加700,000件）です。元データの合計と検索可能なユニーク曲数は異なります。日本楽曲の曲名・アーティストを優先して検索します。**カタログ掲載は「歌える曲」を意味しません**。歌える曲は管理者が個別に登録します。

追加700,000件のMusicBrainzデータは世界中の**録音メタデータ**であり、日本のヒット曲ランキングや歌唱可能曲を保証しません。公式データの曲名・アーティスト・録音IDを収録します。初回読み込み負荷を抑えるため、追加分は**曲名かアーティストの先頭2文字以上による前方一致**で検索します。元データから発売年を確実に検証できない曲の発売年は空欄です。

データ出典： https://musicbrainz.org/doc/Canonical_MusicBrainz_data 、 https://vocadb.net/ 、 https://huggingface.co/datasets/amiadesu/VocaDBSongs 、 https://www.wikidata.org/

JASRAC・NexToneの作品コードやカラオケ配信許可は未検証です。歌詞本文・音声は収録していません。

## 保存・セキュリティ上の重要な制約

現行版は**端末内（localStorage）保存のプレビュー構成**です。配信状態・歌唱履歴・配信レポート・リクエスト・管理メモは**別のPCやスマートフォンとリアルタイム同期されません**。利用ブラウザのデータ削除で失われる可能性があります。

管理画面の短いパスワードは**フロントエンドの表示切り替えのみ**で、安全な認証ではありません。公開GitHubリポジトリのコードから確認できるため、機密情報を登録しないでください。公開運用には認証・データアクセス制御を備えた共有バックエンド（例：Supabase）への移行が必要です。

## 自動更新・検証

- `.github/workflows/build-vocadb-catalog.yml`：当初10万曲の収集・検証・分割出力。
- `.github/workflows/extend-catalog-to-300k.yml` と `scripts/extend_catalog_to_300k.py`：既存30万曲のユニーク化。
- `.github/workflows/build-musicbrainz-1m.yml` と `scripts/build_musicbrainz_to_1m.py`：MusicBrainz公式データから重複なし700,000件を収集し、合計1,000,000件を検証。追加分は256個に分割し検索時のみ取得します。
- `tests/smoke.mjs` と `.github/workflows/browser-smoke.yml`：Chromiumでリスナー画面、管理画面、配信切り替え、振り分け、歌唱履歴、調査指示、メモ、配信レポートを回帰テストします。
