# Kenのデンモク（REALITY歌配信向け）

ブラウザで歌唱待機・歌唱履歴・リクエストを管理するGitHub Pagesアプリです。

公開URL: https://y-tools.github.io/ken_ver1/

## リスナー画面

1. **歌唱中曲**とON AIR/OFF AIR表示
2. **01 楽曲検索**：曲名・アーティスト名の独立した2入力欄。片方だけ、または両方を入力してAND絞り込み。かな・ローマ字でも検索
3. **02 歌唱待機楽曲**：順番とリクエスト者を表示
4. **03 本日の歌唱履歴**：歌唱が完了した楽曲、終了時刻を日本時間で表示
5. **04 練習中楽曲**：練習曲を表示

「リクエストする」でフォームをポップアップ表示。配信開始中のみ送信可能。曲名・アーティスト・リクエスト者名を記録します。

## 管理画面

ページタイトルを約0.75秒長押し（PCではダブルクリックも可）すると管理画面への簡易入口が開きます。

PC画面は左から：リスナー画面プレビュー、歌唱待機曲（歌唱開始・完了・取り消し）、未分類リクエスト（歌唱待機・練習中・歌える曲への振り分け）、右端上下2分割の管理メモ・ChatGPT調査連携。

歌唱待機＋歌える曲の同時選択が可能です。配信開始・終了でON AIR表示とリクエスト受付を切り替えます。管理メモと曲ごとのメモ編集、配信レポートもあります。

**「さらに調べる」**は、曲名・アーティストについて楽曲情報、概要、公式歌詞掲載URLを調査するための**プロンプトを生成する機能**です。ChatGPTを新しいタブで開き、内容を貼り付けて利用します。ChatGPTへの自動送信・iframe埋め込み・API問い合わせは行いません。Google歌詞URL検索も別タブで開きます。

## 検索カタログ（2026-11-09 TK限定）

**現在の楽曲データベースには「TK from 凛として時雨」のみを登録しています。**

- `catalog.json` はVPSのTKアーティストID `643167` から抽出した **98曲** のみを保持します。レコード形式は `[曲名, アーティスト名, 確認済み発売年またはnull]` です。
- VPS PostgreSQL `ken_songs` にも、TK 1アーティスト、98曲、309録音を維持します。検索APIの検索対象はこれらに限定します。
- 過去の約200万曲の静的分割JSON、推定読みバケット、VocaDB/MusicBrainz大量データ、旧大量収集ジェネレーターは現在のブランチから削除しています。自動再生成ワークフローも停止・削除しました。
- 削除前の静的データはGitHubの `backup/ken-pre-tk-only-20261109` ブランチに、削除前のVPS全データは `/var/backups/ken-songs/ken_full_before_tk_only_20261109_tk_only.dump` に保存しています。
- 検索画面は、曲名とアーティスト名の個別/同時AND検索を維持し、ブラウザキャッシュが旧データを保持していてもTK以外を結果に追加しません。
- リクエスト履歴・歌唱履歴・端末ごとの管理メモ・カラオケ確認記録は、別のローカルデータであり、**カタログ削除では消去されません**。TK以外の過去リクエストの表示はデータベースの曲が残っていることを意味しません。

※ 98曲は既存DBに登録された暫定的な曲名の件数です。公式全ディスコグラフィーの網羅性を保証しません。出典付きの発売日や正式な読みが未確認の曲は空欄にします。

## DAM / JOYSOUND 公式収録情報の確認

- 楽曲検索・受付リクエスト・歌唱待機・登録済み曲に、**DAM / JOYSOUND** の公式検索リンクと確認状況パネルを表示します。公式の入口は https://www.clubdam.com/karaokesearch/ と https://www.joysound.com/web/search です。曲名・アーティストを指定したサイト内検索の補助リンクも付属します。
- 表示状態は **未確認**、**公式で配信確認済み**、**公式検索で見つからず（未配信確定ではない）** の3つです。TKの登録済み98曲は基本的に未確認です。利用可能な公式全曲配信データフィードを確認できていないため、DAM・JOYSOUNDの収録曲を自動的に全曲照合済みとすることはできません。
- 管理画面から曲ごとに、DAM/JOYSOUNDの確認結果・個別公式ページURL・曲番号・確認日・機種メモを保存できます。配信確認済みとするには根拠の公式個別曲ページURLが必要です。
- CSVで照合履歴を出力・取り込みできます。列は title,artist,dam_status,dam_url,dam_number,dam_checked_at,joysound_status,joysound_url,joysound_number,joysound_checked_at,notes の11列です。確認記録はブラウザ内のlocalStorageに保存されます。
- **カラオケ機種への収録と、REALITY等での歌配信利用許諾は別です。** 配信前に音源の利用条件と権利を確認してください。
## 保存・セキュリティ上の重要な制約

現行版は**端末内（localStorage）保存のプレビュー構成**です。配信状態・歌唱履歴・配信レポート・リクエスト・管理メモは**別のPCやスマートフォンとリアルタイム同期されません**。利用ブラウザのデータ削除で失われる可能性があります。

管理画面の短いパスワードは**フロントエンドの表示切り替えのみ**で、安全な認証ではありません。公開GitHubリポジトリのコードから確認できるため、機密情報を登録しないでください。公開運用には認証・データアクセス制御を備えた共有バックエンド（例：Supabase）への移行が必要です。
